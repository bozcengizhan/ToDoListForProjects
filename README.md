# 🚀 WorkSync

**WorkSync** is a modern **task management / to-do list mobile application** designed for company employees to efficiently manage their daily tasks.
Users can log in using their company email, create tasks, track progress, and mark them as completed.

---

## ✨ Features

* 🔐 Company email authentication
* ➕ Create tasks
* ✅ Mark tasks as completed
* 🗂️ Task listing and tracking
* ⚡ Fast and modern UI built with Jetpack Compose
* 📱 Mobile-first design

---

## 🛠️ Tech Stack

* **Kotlin**
* **Jetpack Compose**
* **Android Studio**
* *(Optional)* Firebase Authentication / Firestore

## 🚀 Getting Started

To run this project locally:

```bash
git clone https://github.com/yourusername/WorkSync.git
```

1. Open the project in Android Studio
2. Wait for dependencies to sync
3. Run the app on an emulator or physical device
